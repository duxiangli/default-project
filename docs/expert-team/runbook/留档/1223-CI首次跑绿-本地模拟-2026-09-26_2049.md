## 1. 模拟方法（为什么不等于真跑）

- 清空所有 `AUTODISPATCH_*` 环境变量 → 贴近 runner 环境；
- 按 CI workflow 的 6 个步骤原样执行；
- **差异**：本机是 Windows + Node v26.9.0，真 runner 是 ubuntu + Node 22；
  权威结论以 GitHub Actions 实跑为准（见提交后 CI 运行结果）。

## 3. 模拟前置修复（否则 CI 首跑必红）

| 问题 | 影响 | 修复 |
| --- | --- | --- |
| `selftest` 用 `mkdtemp(<tmp>/opencode/…)` 但不确保父目录存在 | ubuntu runner 上无 `/tmp/opencode` → ENOENT → **CI 首跑直接失败** | 先 `mkdir(recursive)` 再 mkdtemp |

> 教训：本地 Windows 跑通 ≠ CI 跑通。平台差异（路径分隔符、父目录约定、换行符）必须专门模拟一次。
